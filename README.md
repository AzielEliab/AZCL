# AZCL — AZCorpusLibrary

Local client for the [Aziel Digital Library](https://www.azielcorpuslibrary.net/).

On first run: auto-import every public library file + hashchain.
When online: sync updates into the local vault (append-only).

Dual-surface: human UI + agent/MCP. Apache-2.0. Author: Aziel Eliab.

Status: scaffold — implementation in progress.
